# Robbie mobile (retired)

This Expo app is not maintained. It was retired from the MVP on 2026-10-08 (`docs/mvp-roadmap.md`): phones use the web app, opened from the meeting's link or QR code.

It no longer works with the server's live meetings: it doesn't understand the slim state updates the server sends (only what changed since the last update). It is left here until it is taken out of the workspaces.
